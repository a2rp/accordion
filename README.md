# Accordion

A modern, responsive FAQ accordion built with React, Vite, styled-components, and React Icons. It includes smooth expand/collapse animations, keyboard-friendly controls, responsive layouts, and locally stored Picsum visuals.

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build` or deploy to GitHub Pages with `npm run deploy`.
