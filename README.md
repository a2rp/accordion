# Accordion

A lightweight, responsive, and reusable Accordion component built with React, Vite, and styled-components.

Perfect for FAQs, help centers, documentation, settings pages, and knowledge bases.

## Preview

![Accordion Preview](./preview.png)

## Features

- Responsive design
- Smooth expand and collapse animation
- React Icons
- JSON based data
- Reusable component
- Clean UI
- Dark theme
- Keyboard accessible
- Easy to customize

## Tech Stack

- React
- Vite
- Styled Components
- React Icons
- JavaScript

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

```bash
npm run deploy
```
